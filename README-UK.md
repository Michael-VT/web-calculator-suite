# Calck — калькулятор на одній сторінці

[English](README.md) · [Português](README-PT.md) · **Українська** · [Русский](README-RU.md) · [Français](README-FR.md) · [Deutsch](README-DE.md)

Науковий калькулятор, конвертер величин і валют в одному `index.html`. **Без зовнішніх бібліотек і шрифтів** (інтернет потрібен лише для курсів валют), світла й темна тема, зручний на телефоні.

- **Науковий**: тригонометрія (Deg/Rad), гіперболічні функції, логарифми, степені, відсотки, факторіал, матриці (`det`, `inv`, `transpose`, …), статистика, НСД/НСК, комбінаторика, округлення; історія, `Ans`, клавіатура.
- **Простий**: великі кнопки.
- **Величини**: 12 категорій, зокрема астрономічні та старовинні російські міри.
- **Валюти**: 12 валют, перерахунок в обидва боки, графік курсу, офлайн-режим.

## Запуск

Відкрийте `index.html` у браузері або виконайте `npm start` → http://localhost:8080.

**Переглянути онлайн** (без встановлення): [відкрити калькулятор](https://michael-vt.github.io/web-calculator-suite/) · [попередній варіант calculatorEF](https://michael-vt.github.io/web-calculator-suite/variants/calculatorEF.html) (підвантажує math.js із CDN, потрібен інтернет).

## Тести

```
npm install
npm test
```

| Файл | Що перевіряє |
|---|---|
| `test/engine.test.js` | рушій виразів: арифметика, функції, матриці, помилки, форматування, фаззинг (60 тис. випадкових виразів: лише результат або зрозуміла `CalcError`) |
| `test/converters.test.js` | усі пари одиниць (оборотність), температура, курси, дати й кеш графіка, збої мережі |
| `test/ui.test.js` | справжня сторінка в jsdom: кожна кнопка й набір Fn/Inv, клавіатура, підказки, величини, валюти (онлайн/офлайн), «мавпа» — 6000 випадкових натискань без помилок |
| `test/manual.test.js` | виконує всі приклади з `docs/MANUAL.md`, перевіряє, що описано кожну функцію й кнопку |

Тести запускаються при кожному push через GitHub Actions (`.github/workflows/test.yml`, Node 22).

## Структура

```
index.html            сторінка
css/style.css         оформлення (світла/темна тема)
js/calc-engine.js     розбір і обчислення виразів (без DOM)
js/converters.js      величини й валюти (без DOM)
js/app.js             інтерфейс
docs/                 посібник і документи про архітектуру
test/                 тести
variants/             попередні варіанти сторінки (для історії)
```
