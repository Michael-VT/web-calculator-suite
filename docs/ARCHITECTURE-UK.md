# Архітектура: за що відповідає кожен файл, як працюють функції, як усе перевіряється

[English](ARCHITECTURE.md) · [Português](ARCHITECTURE-PT.md) · **Українська** · [Русский](ARCHITECTURE-RU.md) · [Français](ARCHITECTURE-FR.md) · [Deutsch](ARCHITECTURE-DE.md)

## 1. Огляд

Програма — статична сторінка без збірки й без залежностей часу виконання. Логіка розділена на дві частини, які **не звертаються до DOM** і працюють і в браузері, і в Node (тому їх легко тестувати), та тонкий шар інтерфейсу:

| Файл | Відповідальність |
|---|---|
| `index.html` | розмітка: дисплей, дві клавіатури (наукова / проста), панелі «Величини» та «Валюти», вікна довідки |
| `css/style.css` | оформлення; світла й темна тема через CSS-змінні, адаптивна верстка |
| `js/calc-engine.js` | `CalcEngine`: розбір і обчислення виразів, форматування результату (без DOM) |
| `js/converters.js` | `Converters`: величини, валюти, завантаження курсів, дані для графіка (без DOM) |
| `js/app.js` | інтерфейс: стан, обробка кнопок, клавіатура, режими, малювання графіка, довідка |
| `docs/MANUAL.md` | посібник користувача (російською); його приклади виконуються в тестах |
| `test/` | автоматичні тести (розділ 5) |
| `variants/` | попередні варіанти сторінки, для історії; не розвиваються й не тестуються |

Обидва файли логіки використовують одну обгортку (UMD): `module.exports` у Node, глобальна змінна (`CalcEngine`, `Converters`) у браузері.

## 2. `js/calc-engine.js` — рушій виразів

Публічний інтерфейс: `evaluate(expr, { deg, ans })`, `parse`, `tokenize`, `formatNumber`, `formatValue`, `Matrix`, `CalcError`, `FUNCTIONS`, `FUNCTION_NAMES`, `CONSTANTS`.

### Конвеєр

`evaluate` = `parse` → `evalNode` → усунення `-0`. Будь-яка помилка користувача кидається як `CalcError` зі зрозумілим текстом; інтерфейс показує її та зберігає вираз.

1. **`normalize`** замінює символи відображення на ASCII: `× · ⋅` → `*`, `÷` → `/`, `− – —` → `-`, `π` → `pi`, `√` → `sqrt`.
2. **`tokenize`** ділить текст на числа (`12`, `.5`, `1.5e3`), ідентифікатори й оператори `+ - * / ^ ( ) [ ] , ! %`. Будь-який інший символ викликає помилку «Недопустимий символ».
3. **`parse`** — рекурсивний низхідний розбір в AST. Пріоритети від нижчого до вищого:
   `additive (+ -)` → `term (* /` і неявне множення`)` → `unary (-, +)` → `power (^)` → `postfix (! %)` → `primary`.
   - Неявне множення: `2pi`, `2(3+4)`, `3sin(30)`.
   - `^` правоасоціативна (`2^3^2 = 512`), а `-2^2 = -4` (унарний мінус застосовується після степеня); `2^-3` працює, бо показник розбирається як унарний вираз.
   - Бракуючі закриваючі дужки в кінці вводу закриваються автоматично (`expect` у кінці повертає `null`).
   - Обмеження: 1000 символів, 100 рівнів вкладеності — захист від ворожого вводу.
   - Матриця записується `[[1,2],[3,4]]`: список у дужках; список однорядкових матриць однакової довжини стає багаторядковою матрицею.
4. **`evalNode`** обходить AST. Основні правила:
   - **Відсотки**: `50%` = 0.5; але в `200 + 10%` відсоток береться *від лівого операнда* (= 220); так само для `-`.
   - **Факторіал** визначений для цілих 0…170.
   - **Константи** `pi`, `e` та `Ans` (останній результат, передається в `ctx.ans`).
   - **Виклик функції** звіряє кількість аргументів із реєстром і викликає реалізацію.
5. **`check`** застосовується до кожного результату: `NaN` → «Результат не визначений», `Infinity` → «Переповнення».

### Реєстр функцій

`FUNCTIONS` зіставляє ім'я та `{ n: [min, max], f(args, ctx, name) }`. 46 імен (без синонімів `trans`, `identity`, `fact`):

- тригонометрія та обернені: `sin cos tan asin acos atan atan2` (Deg/Rad через `ctx.deg`); гіперболічні: `sinh cosh tanh asinh acosh atanh`
- експонента, логарифми, корені: `exp ln log10 log2 log sqrt cbrt hypot`
- округлення та знак: `abs sign floor ceil trunc round`
- цілі числа: `factorial ncr npr gcd lcm mod`
- статистика (приймає список або матрицю): `sum mean median min max std stdp`
- матриці: `det inv transpose trace eye size`

Помічники: `ew(f)` застосовує функцію одного числа поелементно (до числа або до кожного елемента матриці); `num`, `ints`, `flat` перевіряють типи аргументів і кидають зрозумілі помилки.

### Точність обчислень

- `clean15` округлює результат до 15 значущих цифр і прибирає шум плаваючої коми (`0.1+0.2` дає `0.3`).
- `cleanTrig` та особливі випадки в `sin/cos/tan` повертають точні значення для точних кутів у градусах (`sin(180) = 0`, `cos(90) = 0`, `tan(90)` → помилка).
- Матриці: `matDet` — метод Гауса з вибором головного елемента; `matInv` — Гауса–Жордана; `pow` підтримує цілі степені квадратної матриці (від'ємні — через обернену).

### Форматування

`formatNumber(v, places)` — фіксований запис із 0–14 знаками, незначущі нулі прибираються; експоненційний запис при `|v| ≥ 1e15` і для значень, які за вибраної точності округлилися б до 0. `formatValue` виводить матриці як `[[a, b], [c, d]]`.

## 3. `js/converters.js` — величини й валюти

### Величини

`UNITS` — таблиця `категорія → { label, units: { код: [назва, коефіцієнт] } }`, де *коефіцієнт* — скільки базових одиниць в одній даній. Перерахунок: `значення × k(з) / k(в)`. 12 категорій: довжина, маса, температура, об'єм, площа, швидкість, час, дані (десяткові та двійкові префікси), астрономічні та три групи старовинних російських мір (довжина, площа, вага).

- **Температура** — особлива категорія: значення переводиться в кельвіни й назад (`toKelvin`, `fromKelvin`); значення нижче абсолютного нуля викликають помилку.
- `convertUnit` перевіряє категорію, одиниці та скінченність числа. `formatUnitValue` виводить 10 значущих цифр, для дуже великих/малих значень — експоненційний запис.

### Валюти

- `CURRENCIES` — 12 валют; `FALLBACK_RATES` — приблизні курси до USD для роботи без мережі.
- `fetchRatesFile` завантажує `usd.min.json` відкритого набору `currency-api`, пробуючи по черзі дві адреси (CDN jsDelivr і `pages.dev`); функція `fetch` передається параметром, тому тести можуть її підмінити.
- `convertCurrency(amount, from, to, rates)` = `amount × rates[to] / rates[from]` (усі курси задано до USD, тому підходить будь-яка пара).
- Графік: `chartDates(days, today, maxPoints)` вибирає до 24 дат за зростанням, остання — сьогодні; `fetchHistory` завантажує їх **паралельно**, складає в об'єкт-кеш і мовчки пропускає недоступні дати.
- `formatMoney` — розряди й 2…8 знаків залежно від величини.

## 4. `js/app.js` — інтерфейс

- **Стан** — один об'єкт: вираз, попередній вираз, `Ans`, Deg/Rad, Inv, сторінка Fn, історія (до 50 записів, видно останні 3), текст помилки.
- **`PAGES`** — шість наборів Fn (Trig, Hyp, Mat, Stat, Comb, Rnd); у кожного 6 слотів, слот може задавати заміну `inv` для ввімкненого Inv.
- **`insert(val)`** — захист вводу. Не дає набрати хибну послідовність: два оператори поспіль (останній замінює попередній), друга крапка в числі, початковий `0` перед цифрою, закриваюча дужка без відкриваючої, `%`/`!` без операнда, кома поза дужками. Після `=` цифра починає новий вираз, а оператор продовжує від `Ans`.
- **`backspace`** видаляє ім'я функції (`sin(`), `Ans` або `pi` цілком; **`calculate`** викликає `CalcEngine.evaluate`, веде історію, показує повідомлення `CalcError`, не втрачаючи ввід.
- **Режими** — Науковий, Простий, Величини, Валюти; вираз спільний у перших двох.
- **Клавіатура** — цифри й оператори, `Enter`/`=`, `Esc`/`Delete` (скидання), `Backspace`, `x` як множення, `,` як десяткова крапка (або роздільник аргументів у дужках). Ігнорується в полях вводу, при відкритій довідці та в інших режимах.
- **Величини / Валюти** — заповнюють списки з `Converters`, перераховують при кожній зміні; поля суми й результату працюють в обидва боки.
- **Графік курсу** — малюється на `<canvas>`; кожен запит отримує `token`, тому повільна застаріла відповідь не затре нову; підказка при наведенні/дотику.
- **Мережа** — `fetchJson` додає тайм-аут 8 секунд; при збої застосунок переходить на офлайн-курси й повідомляє про це.
- **Довідка** — модальні вікна: закриваються кнопкою, кліком поза вікном або `Esc`.

## 5. Як усе перевіряється й тестується

```
npm install     # встановлює jsdom (єдина dev-залежність)
npm test        # node --test "test/*.test.js" — 72 тести
```

Використовується вбудований у Node запуск тестів; тестовий фреймворк не потрібен.

| Файл | Підхід |
|---|---|
| `test/engine.test.js` | табличні перевірки арифметики, пріоритетів, відсотків, факторіалу, констант, тригонометрії в градусах і радіанах, логарифмів, НСД/НСК/nCr/nPr, статистики, матриць, форматування; кожне повідомлення про помилку; перевірка реєстру (у кожної функції є діапазон аргументів і реалізація); **фаззинг** — 60 000 випадкових рядків мають дати число/матрицю або `CalcError`, але не інший виняток |
| `test/converters.test.js` | типові перерахунки, крайні випадки температури, повний перебір пар одиниць кожної категорії (скінченні числа, A→B→A повертає початкове), завантаження курсів із запасною адресою та помилками, дати графіка, паралельна історія з кешем і пропусками, формат грошей — із підробленим `fetch` |
| `test/ui.test.js` | завантажує справжній `index.html` з усіма скриптами в **jsdom** (`test/helpers/dom.js` підставляє підроблені `fetch` і canvas) і керує ним як користувач: кожна кнопка й набір Fn/Inv, випадки захисту вводу, історія, точність, Deg/Rad, клавіатура, режими, довідка, величини, валюти онлайн/офлайн; а також **«мавпа»** (6000 випадкових натискань і клавіш без жодної помилки сторінки) і перевірка «немає мертвих кнопок» |
| `test/manual.test.js` | розбирає `docs/MANUAL.md`: приклади `` `вираз` → **результат** `` обчислює рушій, приклади «натисніть …» виконуються на справжній сторінці, приклади `rad:` і `units:` використовують свій режим; також перевіряє, що згадано всі функції рушія й усі кнопки інтерфейсу, а посібник посилається лише на наявні файли й команди |

Наслідок: якщо поведінка функції змінилася, впаде або модульний тест, або тест посібника — код, посібник і тести не можуть розійтися. CI (`.github/workflows/test.yml`) виконує `npm install && npm test` на Node 22 при кожному push і pull request.

### Як додати функцію

1. Додайте запис у `FUNCTIONS` у `js/calc-engine.js` (і, якщо потрібна кнопка, слот у `PAGES` у `js/app.js`).
2. Додайте модульні тести в `test/engine.test.js`.
3. Опишіть її в `docs/MANUAL.md` з прикладом, що виконується, `` `f(2)` → **4** ``; доки описано не всі функції, `test/manual.test.js` падатиме.

## 6. `variants/`

Попередні самостійні сторінки (`calculatorEF.html` — основа поточної версії, `calculator-manual.html` — колишній мануал). У тестах не беруть участі.
