# Руководство пользователя

Калькулятор состоит из четырёх режимов: **Научный**, **Величины**, **Простой**, **Валюты**.
Откройте `index.html` в браузере — установка не нужна, интернет требуется только для актуальных курсов валют.

> **Все примеры в этом руководстве проверяются автоматически** (`npm test`, файл `test/manual.test.js`).
> Если вы видите запись вида «`2+3*4` → **14**», это значит: введите `2+3*4`, нажмите `=` — получите `14`.
> Если пример когда-нибудь перестанет совпадать с программой, тесты упадут.

Условные обозначения:

| Запись | Значение |
|---|---|
| `2+3*4` → **14** | Набрать выражение (кнопками или с клавиатуры) и нажать `=` |
| Нажмите `1 2 + 3 4 =` | Последовательность кнопок, как они подписаны на экране |
| → **ошибка: …** | Калькулятор покажет сообщение об ошибке под результатом |

Если не сказано иное, примеры считаются в режиме **Deg** (градусы) и с точностью **6 знаков**.

## 1. Экран

```
   10+5 = 15          ← история (последние 3 строки; нажмите на строку, чтобы вернуть выражение)
   20×3 = 60
   20×3 =             ← выражение, которое только что вычислено
   60                 ← основной дисплей: набираемое выражение или результат
   Деление на ноль    ← сообщение об ошибке (красным)
```

- Пока вы набираете, на дисплее видно **выражение**. После `=` — **результат**, а над ним выражение со знаком «=».
- После результата можно сразу нажать оператор — вычисление продолжится с результатом: нажмите `5 + 3 = × 2 =` → **16**.
  Если вместо оператора нажать цифру или функцию, начнётся новое выражение.
- **Ошибка не стирает выражение**: исправьте его через `⌫` и нажмите `=` снова.
- Селектор **«Знаков после запятой»** (2, 4, 6, 8, 10, 14) сразу пересчитывает показанный результат и историю.
  Хранится полное значение, поэтому `Ans` не теряет точность.

Попробуйте сами: нажмите `1 ÷ 3 =` и меняйте селектор точности — результат будет `0.33`, `0.333333`, `0.3333333333`.

- Нажмите `1 ÷ 3 =` → **0.333333**

## 2. Научный режим: кнопки

```
 Deg   Fn   (    )    %    AC   ⌫
 Inv   f1   f2   7    8    9    ÷
 π     f3   f4   4    5    6    ×
 e     f5   f6   1    2    3    −
 Ans   EXP  xʸ   0    .    =    +
 [     ]    ,    x²   x⁻¹  n!   abs
```

`f1`…`f6` — шесть кнопок, которые меняются при нажатии **Fn** и **Inv** (см. раздел 3).

### 2.1 Основные кнопки

| Кнопка | Что делает | Пример |
|---|---|---|
| `0`–`9`, `.` | Ввод числа. Вторую точку в числе и лишние нули в начале программа не даёт ввести. | Нажмите `1 . 5 + 2 . 5 =` → **4** |
| `+` `−` `×` `÷` | Арифметика. Если нажать два оператора подряд — второй заменит первый. Минус после `×` `÷` `xʸ` — это знак числа. | Нажмите `5 + × 3 =` → **15** |
| `=` | Вычислить. Пустой ввод игнорируется. | Нажмите `7 × 8 =` → **56** |
| `( )` | Скобки. Лишнюю `)` программа не вставит. Незакрытые скобки в конце закрываются сами. | `(2+3)*4` → **20** |
| `%` | Процент. Само по себе — «/100». После `+` или `−` — процент **от левого числа** (как на бытовом калькуляторе). | `50%` → **0.5** |
| `xʸ` | Возведение в степень (`^`). Правоассоциативно: `2^3^2 = 2^9`. | Нажмите `2 xʸ 1 0 =` → **1024** |
| `x²` | Возводит последнее число или скобку в квадрат (дописывает `^2`). | Нажмите `3 x² =` → **9** |
| `x⁻¹` | Обратное число (дописывает `^(-1)`). | Нажмите `4 x⁻¹ =` → **0.25** |
| `n!` | Факториал последнего числа (дописывает `!`). Целые от 0 до 170. | Нажмите `5 n! =` → **120** |
| `abs` | Модуль: вставляет `abs(`. | Нажмите `abs - 3 ) =` → **3** |
| `π`, `e` | Константы 3.14159… и 2.71828…. Перед ними автоматически ставится «×», если нужно. | Нажмите `2 π =` → **6.283185** |
| `EXP` | Запись «×10ⁿ»: вставляет `E`. `5 EXP 3` — это `5E3` = 5000. Привязана к числу, поэтому `1/5 EXP 3` = 1/5000. | Нажмите `5 EXP 3 =` → **5000** |
| `Ans` | Подставляет предыдущий результат (с полной точностью). | Нажмите `1 0 0 ÷ 4 = Ans × 2 =` → **50** |
| `AC` | Полный сброс: выражение, результат, история, ошибка. | Нажмите `1 + 2 = AC` → **0** |
| `⌫` | Стирает последний символ; **функцию (`sin(`), `Ans` и `π` — целиком**. После результата только убирает подпись «выражение =». | Нажмите `2 + sin( ⌫ 3 =` → **5** |
| `Deg` / `Rad` | Углы в градусах или радианах. Кнопка показывает **текущий** режим; в `Rad` она красная. | см. 2.2 |
| `[` `]` `,` | Матрицы и списки аргументов: `[[1,2],[3,4]]`, `gcd(12,18)`. Запятая вне скобок на клавиатуре превращается в десятичную точку. | `[1,2,3]` → **[1, 2, 3]** |

### 2.2 Градусы и радианы

- Нажмите `sin( 3 0 =` → **0.5**
- `rad: sin(pi/2)` → **1**
- `rad: cos(pi)` → **-1**
- `rad: atan(1)*4` → **3.141593**

Нажмите `Deg` один раз — надпись сменится на `Rad`, и `sin(30)` уже не равен 0.5.

### 2.3 Проценты

| Ввод | Результат | Как считается |
|---|---|---|
| `50%` → **0.5** | | просто делится на 100 |
| `200+10%` → **220** | | 200 + 10 % от 200 |
| `200-10%` → **180** | | 200 − 10 % от 200 |
| `200*10%` → **20** | | 200 × 0.1 |
| `50%%` → **0.005** | | процент можно применять повторно |

### 2.4 Правила записи выражений

- Приоритет: `!` `%` → `^` → унарный минус → `×` `÷` → `+` `−`. Поэтому `-2^2` → **-4**, а `(-2)^2` → **4**.
- `2^3^2` → **512** (степень считается справа налево).
- Неявное умножение: `2pi` → **6.283185**, `2(3+4)` → **14**, `(1+2)(3+4)` → **21**.
- Незакрытые скобки: `sqrt(16` → **4**, `2*(3+(4` → **14**.
- Шум чисел с плавающей точкой убирается: `0.1+0.2` → **0.3**, `0.1+0.2-0.3` → **0**.
- Знак «−» в записи можно вводить и как `-`, и как `−`; «×» и «÷» — как `*` и `/`.

## 3. Наборы функций: кнопки Fn и Inv

Кнопка **Fn** (она подписана названием текущего набора) по кругу переключает шесть наборов:
**Trig → Hyp → Mat → Stat → Comb → Rnd → Trig**. Кнопка **Inv** включает «обратные» функции там, где они есть
(кнопка подсвечивается синим, надписи меняются).

Все функции записываются так: имя, скобка, аргументы через запятую, `)`. Закрывающую скобку в конце можно не ставить.

### 3.1 Trig — тригонометрия, логарифмы, корень

| Слот | Обычно | С `Inv` | Примеры |
|---|---|---|---|
| f1 | `sin(` | `asin(` | `sin(30)` → **0.5**; Нажмите `Inv asin 0 . 5 =` → **30** |
| f2 | `ln(` | `exp(` (eˣ) | `ln(e)` → **1**; `exp(0)` → **1** |
| f3 | `cos(` | `acos(` | `cos(60)` → **0.5**; `acos(0.5)` → **60** |
| f4 | `log(` | `10^` (10ˣ) | `log(1000)` → **3**; `log(8, 2)` → **3**; Нажмите `Inv 10ˣ 3 =` → **1000** |
| f5 | `tan(` | `atan(` | `tan(45)` → **1**; `atan(1)` → **45** |
| f6 | `sqrt(` (√) | `^2` (x²) | `sqrt(16)` → **4**; Нажмите `Inv 5 x² =` → **25** |

- `log(x)` — **десятичный** логарифм, `ln(x)` — натуральный, `log(x, основание)` — по любому основанию.
- В режиме Deg обратные функции возвращают градусы: `asin(1)` → **90**, `atan2(1, -1)` → **135**.
- `tan(90)` → **ошибка: tan не определён для этого угла**.
- `asin(2)` → **ошибка: asin: аргумент должен быть от −1 до 1**.
- `ln(0)` → **ошибка: Логарифм определён только для x > 0**.
- `sqrt(-4)` → **ошибка: Корень из отрицательного числа**.

### 3.2 Hyp — гиперболические функции, log₂, кубический корень

| Слот | Обычно | С `Inv` | Примеры |
|---|---|---|---|
| f1 | `sinh(` | `asinh(` | `sinh(0)` → **0**; `asinh(0)` → **0** |
| f2 | `log2(` | `2^` (2ˣ) | `log2(8)` → **3**; Нажмите `Fn Inv 2ˣ 1 0 =` → **1024** |
| f3 | `cosh(` | `acosh(` | `cosh(0)` → **1**; `acosh(1)` → **0** |
| f4 | `cbrt(` | `^3` (x³) | `cbrt(27)` → **3**; `cbrt(-8)` → **-2** |
| f5 | `tanh(` | `atanh(` | `tanh(0)` → **0**; `atanh(0)` → **0** |
| f6 | `atan2(` | — | `atan2(1, 1)` → **45**; `atan2(1, -1)` → **135** |

- `acosh(0.5)` → **ошибка: acosh: аргумент должен быть не меньше 1**.
- `atanh(1)` → **ошибка: atanh: аргумент должен быть строго между −1 и 1**.
- Без кнопки: `hypot(3, 4)` → **5** (длина гипотенузы), `exp(x)`.

### 3.3 Mat — матрицы

Матрица вводится как `[[1,2],[3,4]]` — строки в скобках, через запятую. Строка-вектор: `[1,2,3]`.

| Слот | Функция | Что делает | Пример |
|---|---|---|---|
| f1 | `det(` | определитель квадратной матрицы | `det([[1,2],[3,4]])` → **-2** |
| f2 | `inv(` | обратная матрица | `inv([[1,2],[3,4]])` → **[[-2, 1], [1.5, -0.5]]** |
| f3 | `transpose(` (на кнопке `trans`) | транспонирование | `transpose([[1,2],[3,4]])` → **[[1, 3], [2, 4]]** |
| f4 | `trace(` | след (сумма диагонали) | `trace([[1,2],[3,4]])` → **5** |
| f5 | `eye(` | единичная матрица n×n | `eye(3)` → **[[1, 0, 0], [0, 1, 0], [0, 0, 1]]** |
| f6 | `size(` | размер: `[строки, столбцы]` | `size([[1,2,3],[4,5,6]])` → **[2, 3]** |

Арифметика с матрицами:

| Операция | Пример | Результат |
|---|---|---|
| сложение / вычитание (одинакового размера) | `[[1,2],[3,4]]+[[1,1],[1,1]]` | **[[2, 3], [4, 5]]** |
| умножение на число | `2*[[1,2],[3,4]]` | **[[2, 4], [6, 8]]** |
| деление на число | `[[2,4],[6,8]]/2` | **[[1, 2], [3, 4]]** |
| произведение матриц | `[[1,2],[3,4]]*[[0,1],[1,0]]` | **[[2, 1], [4, 3]]** |
| целая степень | `[[1,1],[0,1]]^3` | **[[1, 3], [0, 1]]** |
| обратная через степень | `[[2,0],[0,2]]^-1` | **[[0.5, 0], [0, 0.5]]** |
| функции действуют на каждый элемент | `sqrt([4,9])` | **[2, 3]** |
| проверка обратной | `[[1,2],[3,4]]*inv([[1,2],[3,4]])` | **[[1, 0], [0, 1]]** |

Чтобы дойти до набора `Mat`, нажмите `Fn` два раза (Trig → Hyp → Mat). Полностью: нажмите `Fn Fn det [ [ 1 , 2 ] , [ 3 , 4 ] ] ) =` → **-2**.

Матричные ошибки:

- `inv([[1,2],[2,4]])` → **ошибка: Матрица вырождена (определитель равен 0)**
- `det([[1,2,3],[4,5,6]])` → **ошибка: det: матрица должна быть квадратной**
- `[[1,2]]+1` → **ошибка: Нельзя складывать матрицу и число**
- `[[1,2]]*[[1,2]]` → **ошибка: Нельзя умножить матрицы 1×2 и 1×2**
- `[[1,2],[3]]` → **ошибка: Некорректная матрица: строки должны быть одной длины**

### 3.4 Stat — статистика

Функции принимают список (`[1,2,3]`), матрицу (все элементы) или числа через запятую (`mean(1,2,3)`).

| Слот | Функция | Что делает | Пример |
|---|---|---|---|
| f1 | `mean(` | среднее | `mean([1,2,3,4])` → **2.5** |
| f2 | `median(` | медиана | `median([5,1,3])` → **3**; `median([1,2,3,4])` → **2.5** |
| f3 | `sum(` | сумма | `sum([1,2,3,4])` → **10**; `sum(1,2,3)` → **6** |
| f4 | `std(` | стандартное отклонение **выборки** (n−1) | `std([2,4,4,4,5,5,7,9])` → **2.13809** |
| f5 | `min(` | минимум | `min([4,2,8])` → **2** |
| f6 | `max(` | максимум | `max(4, 2, 8)` → **8** |

Только с клавиатуры: `stdp(` — стандартное отклонение **генеральной совокупности** (n): `stdp([2,4,4,4,5,5,7,9])` → **2**.

- `std([5])` → **ошибка: std: нужно минимум 2 значения**

### 3.5 Comb — числа и комбинаторика

| Слот | Функция | Что делает | Пример |
|---|---|---|---|
| f1 | `gcd(` | НОД двух и более целых | `gcd(12, 18)` → **6**; `gcd(12, 18, 30)` → **6** |
| f2 | `lcm(` | НОК | `lcm(12, 18)` → **36** |
| f3 | `nCr(` | сочетания C(n, k) | `nCr(5, 2)` → **10**; `nCr(52, 5)` → **2598960** |
| f4 | `nPr(` | размещения A(n, k) | `nPr(5, 2)` → **20** |
| f5 | `mod(` | остаток (знак как у делителя) | `mod(10, 3)` → **1**; `mod(-1, 3)` → **2** |
| f6 | `hypot(` | √(a²+b²+…) | `hypot(3, 4)` → **5** |

- `gcd(1.5, 2)` → **ошибка: gcd: нужны целые числа**
- `mod(5, 0)` → **ошибка: Деление на ноль**

### 3.6 Rnd — округление

| Слот | Функция | Что делает | Пример |
|---|---|---|---|
| f1 | `round(` | к ближайшему целому (0.5 — от нуля); второй аргумент — знаков после запятой (0–14) | `round(2.5)` → **3**; `round(-2.5)` → **-3**; `round(3.14159, 2)` → **3.14** |
| f2 | `floor(` | вниз | `floor(2.7)` → **2**; `floor(-2.1)` → **-3** |
| f3 | `ceil(` | вверх | `ceil(2.1)` → **3**; `ceil(-2.7)` → **-2** |
| f4 | `trunc(` | отбросить дробную часть | `trunc(-2.7)` → **-2** |
| f5 | `sign(` | знак: −1, 0, 1 | `sign(-3)` → **-1** |
| f6 | `abs(` | модуль | `abs(-5)` → **5** |

Набор `Rnd` — пятое нажатие `Fn`: нажмите `Fn Fn Fn Fn Fn round 2 . 5 ) =` → **3**.

### 3.7 Факториал и синонимы

- `factorial(5)` → **120** (то же, что кнопка `n!` и запись `5!`); `(2+3)!` → **120**; `3!^2` → **36**.
- `171!` → **ошибка: Факториал определён для целых от 0 до 170**.
- Синонимы: `trans(` = `transpose(`, `identity(` = `eye(`, `fact(` = `factorial(`.
- Переполнение: `10^400` → **ошибка: Переполнение: число слишком велико**.
- `1/0` → **ошибка: Деление на ноль**.

## 4. История, Ans и клавиатура

- Нажмите `1 0 + 5 =` и `2 0 × 3 =` — в истории появятся строки «10+5 = 15» и «20×3 = 60».
  Нажмите на строку — выражение вернётся в ввод, его можно исправить.
- `Ans` — результат последнего вычисления. Нажмите `1 0 0 ÷ 4 = Ans × 2 =` → **50**.

### Клавиатура компьютера

| Клавиша | Действие |
|---|---|
| `0`–`9`, `.` | цифры |
| `+` `-` `*` `/` `^` | операции (`x` тоже означает «×») |
| `(` `)` `[` `]` | скобки |
| `,` | запятая внутри скобок; вне скобок — десятичная точка (удобно на цифровом блоке) |
| `!` `%` | факториал, процент |
| `Enter` или `=` | вычислить |
| `Esc` или `Delete` | AC |
| `Backspace` | стереть |

Клавиатура не работает, пока вы вводите данные в полях («Величины», «Валюты»), пока открыта подсказка (`Esc` закрывает её)
и если зажаты `Ctrl`/`Cmd`/`Alt` (чтобы не мешать сочетаниям браузера).

## 5. Простой режим

Крупные кнопки: `AC`, `⌫`, `%`, `÷`, `×`, `−`, `+`, цифры, `.`, `=`. Выражение и история общие с научным режимом.

- Нажмите `1 2 + 3 4 =` → **46**
- Нажмите `7 × 8 =` → **56**
- Нажмите `1 0 ÷ 4 =` → **2.5**
- Нажмите `2 0 0 + 1 0 % =` → **220**

## 6. Величины

Выберите **категорию**, введите **значение**, выберите единицы «из» и «в» — результат появится сразу.
Кнопка **⇄** меняет единицы местами. Пустое поле даёт «—». Результат показывается с 10 значащими цифрами.

Категории: Длина, Масса, Температура, Объём, Площадь, Скорость, Время, Данные, Астрономические, Старинные (длина / площадь / вес).

Попробуйте (формат: категория | значение | из | в):

- `units: Длина | 1 | метр | км` → **0.001 км**
- `units: Длина | 1 | миля | метр` → **1609.344 метр**
- `units: Температура | 0 | °C | °F` → **32 °F**
- `units: Температура | 100 | °C | °F` → **212 °F**
- `units: Температура | 0 | °C | Кельвин` → **273.15 Кельвин**
- `units: Температура | -300 | °C | °F` → **Ниже абсолютного нуля**
- `units: Масса | 1 | кг | грамм` → **1000 грамм**
- `units: Объём | 1 | литр | мл` → **1000 мл**
- `units: Скорость | 36 | км/ч | м/с` → **10 м/с**
- `units: Время | 1 | день | час` → **24 час**
- `units: Данные | 1 | КиБ (1024 Б) | байт` → **1024 байт**
- `units: Данные | 1 | КБ (1000 Б) | байт` → **1000 байт**
- `units: Астрономические | 1 | а.е. | км` → **149597870.7 км**

- `units: Старинные (длина) | 1 | аршин | вершок` → **16 вершок**
- `units: Старинные (площадь) | 1 | десятина (2400 кв. саж.) | кв. сажень` → **2400 кв. сажень**
- `units: Старинные (вес) | 1 | пуд (40 фунтов) | фунт (русский)` → **40 фунт (русский)**
- `units: Старинные (вес) | 1 | пуд (40 фунтов) | кг` → **16.3804964 кг**

Единицы в «Данных»: **КБ/МБ/ГБ/ТБ** — десятичные (1000), **КиБ/МиБ/ГиБ/ТиБ** — двоичные (1024). Год — 365,25 суток.
Старинные меры — по официальным соотношениям (сажень = 2,1336 м, 1 верста = 500 саженей, 1 десятина = 2400 кв. саженей,
1 пуд = 40 фунтов = 16,3805 кг, 1 фунт = 32 лота = 96 золотников).

## 7. Валюты

1. Вверху — крупный результат: «100 Доллар США равно 4 019,00 Гривна».
2. Введите сумму в **верхнее** поле — нижнее пересчитается; можно вводить и в **нижнее** — тогда пересчитается верхнее.
3. Выберите валюты в списках (12 валют: USD, EUR, UAH, PLN, RUB, GBP, CHF, JPY, CNY, CAD, CZK, TRY). Кнопка **⇅** меняет валюты местами.
4. Строка под результатом показывает дату курсов. **«Обновить»** перезагружает курсы.
5. **График** показывает курс пары за период 7Д, 1М, 3М, 6М, 1Г. Проведите пальцем/мышью по графику — появится значение на дату.
6. Таблица внизу — курсы всех валют к USD.

Как считается: курс пары = `курс(в) / курс(из)`, где курсы заданы к доллару США. Если 1 USD = 40 UAH, то
100 USD = 4000 UAH, а 100 UAH = 2,5 USD.

Источник данных — открытый [currency-api](https://github.com/fawazahmed0/currency-api) (с запасным адресом).
**Без интернета** показываются приблизительные запасные курсы с пометкой «Офлайн-курсы (приблизительные)», график
пишет «Нет данных». Для расчётов с деньгами сверяйтесь с курсом вашего банка.

## 8. Подсказки «?»

Кнопка `?` рядом с точностью открывает краткую справку (4 страницы: «Далее / Назад / Готово»). В режимах «Величины» и «Валюты»
у `?` своя справка. Закрыть: кнопка «Закрыть», клик вне окна или `Esc`.

## 9. Таблица сообщений об ошибках

| Сообщение | Причина | Пример |
|---|---|---|

| Выражение неполное | выражение заканчивается оператором | `2+` |
| Пустое выражение | нечего считать (кнопка `=` при пустом вводе просто ничего не делает) | — |

| Неизвестное имя «…» / Неизвестная функция «…» | опечатка в имени | `foo`, `foo(1)` |
| После «sin» ожидается «(» | функция без скобки | `sin` |
| …: аргументов … | неверное число аргументов | `sin(1,2)` |

## 10. Самопроверка за 10 минут

Пройдите уровни по порядку; каждый пример можно проверить на экране.

**Уровень 1 — арифметика (Научный или Простой).**
Нажмите `1 2 + 3 4 =` → **46**; нажмите `( 2 + 3 ) × 4 =` → **20**; нажмите `2 + 3 × 4 =` → **14**;
нажмите `2 xʸ 1 0 =` → **1024**; нажмите `5 EXP 3 =` → **5000**.

**Уровень 2 — точность, история, Ans.**
Нажмите `1 ÷ 3 =` → **0.333333**, переключите точность на 2 и 10 знаков; нажмите `1 0 + 5 =` и `2 0 × 3 =` — смотрите историю;
нажмите `1 0 0 ÷ 4 = Ans × 2 =` → **50**.

**Уровень 3 — тригонометрия.**
`sin(30)` → **0.5**, `cos(60)` → **0.5**, `tan(45)` → **1**, `asin(0.5)` → **30**, `acos(0.5)` → **60**, `atan(1)` → **45**;
`rad: sin(pi/2)` → **1**.

**Уровень 4 — логарифмы и корни.**
`sqrt(16)` → **4**, `cbrt(27)` → **3**, `ln(e)` → **1**, `log10(1000)` → **3**, `sinh(0)` → **0**, `cosh(0)` → **1**.

**Уровень 5 — матрицы.**
`det([[1,2],[3,4]])` → **-2**, `inv([[1,2],[3,4]])` → **[[-2, 1], [1.5, -0.5]]**, `trace([[1,2],[3,4]])` → **5**, `eye(3)` → **[[1, 0, 0], [0, 1, 0], [0, 0, 1]]**.

**Уровень 6 — статистика и числа.**
`mean([1,2,3,4,5])` → **3**, `factorial(5)` → **120**, `5!` → **120**, `gcd(12,18)` → **6**, `lcm(12,18)` → **36**.

**Уровень 7 — комбинации.**
`sin(atan(1)*2)` → **1**, `sqrt(2^2+3^2)` → **3.605551**, `det([[1,0],[0,1]])*10` → **10**, `mean([1,2,3])+factorial(3)` → **8**.

**Уровень 8 — величины и валюты.**
Во вкладке «Величины»: 0 °C → °F = 32; 1 кг → г = 1000. Во вкладке «Валюты»: введите 100 в верхнее поле,
поменяйте нижнее — верхнее пересчитается; нажмите ⇅ — валюты поменяются местами.
